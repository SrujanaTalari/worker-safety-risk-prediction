# 👷 Worker Safety Risk Prediction Dashboard

Ee project worker safety risk ni predict chestundi mariyu oka intuitive dashboard dwara data insights ni chupisthundhi.

## 🚀 Project Overview
- **Goal:** Safety logs mariyu worker data ni use chesi risk levels predict cheyadam.
- **Tech Stack:** Python, Streamlit, Pandas, Seaborn, Scikit-learn.

## 📂 Repository Structure
* `dashboard.py`: Streamlit dashboard ki main entry point.
* `model.py`: Risk prediction logic mariyu model training.
* `preprocessing.py`: Data cleaning mariyu feature engineering.
* `requirements.txt`: Project ki kavalsina libraries list.
